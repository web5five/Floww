# Floww — Flow Wallet

Floww is a team project for bounded AI spending: the user confirms a mandate, the AI proposes actions, and deterministic checks enforce the permitted scope.

Floww는 사용자가 승인한 지출 범위 안에서 AI가 행동을 제안하고, 코드로 한도를 집행하는 팀 프로젝트입니다.

This repository is the integration and submission hub. Product code remains in separate repositories; this initial commit establishes a reviewable base, not a working release.

이 저장소는 실행·검증·제출의 진입점입니다. 제품 코드는 아래 저장소에 유지하며, 이 초기 커밋은 검토 기반을 만드는 단계입니다.

- [Client](https://github.com/web5five/Floww_Frontend_Client)
- [Server](https://github.com/web5five/Floww_Server)
- [Admin](https://github.com/web5five/Floww_Frontend_Admin)
- [Contracts](https://github.com/web5five/Floww_SmartContract)

No live payment, wallet approval or completed purchase is claimed by this bootstrap. Exact component versions, runnable commands and evidence will be added after verification.
